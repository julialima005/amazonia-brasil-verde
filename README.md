# Amazônia: Brasil Verde 🌿

Site acadêmico desenvolvido durante a graduação em Engenharia de Software na UDF, para praticar a estruturação de páginas com HTML e a estilização com CSS.

## Sobre o projeto

O site apresenta informações introdutórias sobre a Amazônia e uma galeria de imagens. Também inclui um mapa incorporado e uma interface de formulário de contato.

## Tecnologias utilizadas

- HTML5
- CSS3

## Como executar

1. Clique em **Code → Download ZIP** neste repositório.
2. Extraia o arquivo ZIP.
3. Abra o arquivo `index.html` em um navegador.

Não é necessário instalar dependências. O mapa incorporado precisa de conexão com a internet.

Para clonar usando Git:

```bash
git clone https://github.com/julialima005/amazonia-brasil-verde.git
cd amazonia-brasil-verde
```

Depois, abra o arquivo `index.html` no navegador.

## Organização dos arquivos

- `index.html`: estrutura e conteúdo da página.
- `CSS/style.css`: estilos do site.
- `img/`: imagens utilizadas no projeto.

## Limitações atuais

- O formulário de contato é apenas visual e não envia mensagens.
- O mapa incorporado aponta para o campus da UDF.

## Aprendizados

Prática de HTML e CSS, navegação por seções, uso de imagens, incorporação de mapa e organização dos arquivos de um projeto web.
